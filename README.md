# blazquez_duran_Jesus_dise-o_web

Entrega final Tarea 3

Esta web es una pagina de torneos online creada y diseñada por Jesús Blázquez Durán. La web esta diseñada para torneos de videojuegos, y cuenta con las siguientes funcionalidades:

- Login
- Registro
- Torneos
- Partidas
- Perfil
- Configuración

La web esta diseñada con HTML, CSS y elementos puntuales de JavaScript.

En los archivos CSS y HTML se han implementado comentarios para explicar el código.

El codigo incluye:

- Responsive design
- Dark mode (solo funcional en la parte de torneos y perfil, se soluciona en futuras entregas)
- Animaciones
- Interactividad
- Multilenguaje (Ingles y Español)

Además de todos estos elementos, se han añadido:
-Elementos interactivos en el header
-Elementos visuales mejorados
-Optimizacion del codigo CSS
-Optimizacion del codigo HTML
-Optimizacion del codigo JavaScript
-Errores corregidos
-Mejoras en el rendimiento

Gracias por su atención, espero que disfrute de la pagina
